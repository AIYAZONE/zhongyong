# 中庸 · 三十三天共读

> 一天一章，三十三天通读《中庸》。一个零依赖、单文件、可直接打开的共读阅读器。

## 项目简介

《中庸》相传为孔子之孙子思所作，南宋朱熹将其与《大学》《论语》《孟子》合为《四书》，并依《中庸章句》分为**三十三章**。本书按朱熹分章编录，设计为一「**一天一章，三十三天通读**」的社群共读工具：设置开始日期后，「今日共读」会自动定位当天章节；每章均可一键「分享本章」生成直达该章的链接，书友点开即跳到该章。

- **底本**：朱熹《四书章句集注·中庸章句》三十三章（与《礼记·中庸》交叉校对一致）
- **文本**：简体化（opencc tw2s + 人工修正），正文约 3598 字（不含标点）
- **形态**：纯静态单文件 `index.html`，数据全部内联，**无需构建、无后端**

**线上站点**：[zhongyong.aiyazone.com](https://zhongyong.aiyazone.com)（本仓库 `index.html` 部署）

## 功能特性

### 阅读
- 目录导航 + 进度条，目录带日程日期，可一键「跳到今日章」
- URL `#ch-N` 直达定位，便于在微信群分享某一章
- 双阅读模式：分页（一章一页，支持键盘 / 翻页）/ 连续长页，自由切换
- 手机优先、浅色仿书版式；PC 端左侧固定目录栏（窄屏折叠为抽屉）

### 每章内容（七标签）
- **译文**：逐句「原文 ↔ 今译」对照
- **注释**：疑难字注音（ruby 标音）、通假 / 异读虚线提示（点按看说明）
- **串讲**：义理疏通 + 常见误读辨析（以经解经）
- **解读**：程朱理学 / 陆王心学 / 现代视界 / 生活启发 四视角
- **导读**
- **省察**：章末自省提问 +「我的践行笔记」（本机保存）
- **朱注**：朱熹《中庸章句》章首按语摘录

### 研读专区
结构脉络 · 核心概念词典 · 名句摘录 · 中庸与当代焦虑 · 以经解经专题 · 参考书目 · 人物小传 · 章间呼应表 · 四书互参

### 今日安心签
封面独立卡片，每天一句与当日章节呼应、对症现代焦虑的心安之语，可「分享这句」。

### 工具箱
阅读设置（注音 / 连续阅读）· 共读设置（开始日期）· 我的践行笔记 · 今日安心签 · 分享。

## 使用方式

### 本地预览
直接用浏览器打开 `index.html` 即可（无需服务器）。

### 部署到 Vercel
本仓库即 Vercel 站点源。在 Vercel 导入 `AIYAZONE/zhongyong` 并连接 `main` 分支，推送即自动重新部署。

## 技术说明

- **单文件零依赖**：HTML / CSS / JS 与全部经文、译文、注解数据内联于 `index.html`，不引用任何外部资源（favicon 亦内联为 data URI），可离线打开。
- **分享链接**：每章「分享本章」生成 `当前域名/#ch-N` 直达链接；站点部署在任意域名下均能正确定位（自适应 `location.origin`）。
- **笔记本地保存**：践行笔记仅保存在当前浏览器（localStorage），**不会上传云端**；更换设备、清除缓存后将不可见，建议定期「导出我的 33 天自省」备份。
- **零登录零后端**：本阅读器不含账号登录与云端同步，所有数据均在本地。
