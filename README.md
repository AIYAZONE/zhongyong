# 中庸 · 三十三天共读

> 一天一章，三十三天通读《中庸》。零依赖单文件阅读器。

《中庸》相传为孔子之孙子思所作，朱熹将其与《大学》《论语》《孟子》合为《四书》，依《中庸章句》分为三十三章。

**线上站点**：[zhongyong.aiyazone.com](https://zhongyong.aiyazone.com)

---

## 功能特性

### 阅读
- 目录导航 + 进度条，目录带日程日期，一键「跳到今日章」
- URL `#ch-N` 直达定位，便于社群分享
- 双阅读模式：分页（一章一页 / 键盘翻页）↔ 连续长页
- 手机优先、浅色仿书版式；PC 端左侧固定目录栏

### 每章内容（七标签）
- **译文**：逐句「原文 ↔ 今译」对照
- **注释**：生僻字注音 + 通假/异读虚线提示
- **串讲**：义理疏通 + 常见误读辨析（以经解经）
- **朱注**：朱熹《中庸章句》章首按语摘录
- **解读**：程朱理学 / 陆王心学 / 现代视界 / 生活启发 四视角
- **导读**：本章要旨总结
- **省察**：章末自省提问 +「我的践行笔记」

### 研读专区
结构脉络 · 核心概念词典 · 名句摘录 · 中庸与当代焦虑 · 以经解经专题 · 参考书目 · 人物小传 · 章间呼应表 · 四书互参

## 使用方式

直接用浏览器打开 `index.html` 即可，无需服务器。

### Vercel 部署
导入 `AIYAZONE/zhongyong`，连接 `main` 分支，推送即自动部署。

---

## 技术说明

- **单文件零依赖**：全部数据内联于 `index.html`，无外部资源，可离线使用
- **分享链接**：每章「分享本章」生成 `域名/#ch-N` 直达链接
- **笔记本地保存**：践行笔记存于 localStorage，建议定期导出备份
- **无登录无后端**：纯静态，不含账号与云端同步
